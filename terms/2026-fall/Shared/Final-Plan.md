## Exam Schedule Protection
---
### Back-to-Back Exams

```
Heavy numerical (Arch) + Heavy numerical (Networks):
  → Study Arch first (3 days before)
  → Networks second (2 days before)
  → Night between: 9h sleep, NO studying
  → Accuracy degrades 15-20% per lost sleep hour
```
---
### Same Day Double

```
Stats (analytical morning) + SE (memory afternoon):
  → Practice switching — interleave during revision
  → Lunch: low glycemic, no sugar crash
  → 20-min power nap between papers if possible
```

## Minimum Viable Passing

- If behind: numericals > diagrams > theory
- If severely behind: focus on the 3 Must-Win topics per course
- Accept B+ in project-based courses to protect A in objective courses
