## Instructions

1. Log every mistake within 1 hour of making it
2. For "Why Wrong," choose from:
   - Formula recall failure
   - Calculation arithmetic error
   - Concept misunderstanding
   - Diagram missing component
   - Time pressure mistake
   - Reading the question wrong
3. For "Re-drill," set a date 48h later
4. Before re-drill, do NOT look at the correct answer — attempt from memory first
5. If you get it right on re-drill, mark as ✓. If wrong again, move to 1-week interval
