## Introduction

This workbook assists the conduct of practical classes for CS-318 Computer Communication Networks. Practical work provides students a good grasp of the various topics in computer networks, augmenting classroom teaching with essential practical knowledge.

**Course Learning Outcome (CLO):**
> *"Practice configuration and troubleshooting of computer networks using modern tools."*

A rubric to evaluate student performance is provided at the end of the workbook.

- **Section 1 (Labs 1–3):** Configuration of IP addresses, making network cables, establishing connectivity between devices, and exploring Cisco IOS commands.
- **Section 2 (Labs 4–8):** Routing protocols — static and dynamic — data-link layer protocol and access lists configuration.
- **Section 3 (Labs 9–10):** Basic LAN switch operation, loop avoidance using Spanning Tree Protocol, and Virtual LANs.
- **Section 4 (Labs 11–14):** Advanced topics — NAT, BGP, DHCP, and Wireshark.
- **Appendix A:** IPv4 Addressing, Sub-netting and VLSM.

> **Course-code note:** the workbook is titled CS-318 (the code printed on the lab manual); the blueprint's course playbook is `CCN/` for CS-327 — the practical sessions map 1:1 to the CS-327 lab as listed in `CCN/02-Official-Syllabus.md`.
