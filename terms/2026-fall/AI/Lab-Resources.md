## Lab 9 — Solving CSPs Using Stochastic Local Search Techniques

- [aimacode/aima-python](https://github.com/aimacode/aima-python) — `min_conflicts` hill-climbing heuristic and efficient `NQueensCSP` in csp.py, plus `simulated_annealing` in search.py.
- [calcelli/Min-Conflict-nQueens](https://github.com/calcelli/Min-Conflict-nQueens) — Min-conflicts N-Queens solver (moves random queen to fewest-conflict spot).
- [duncansclarke/N-Queens](https://github.com/duncansclarke/N-Queens) — N-Queens via iterative repair + min-conflicts heuristic.
- [pranav-putta/nqueens](https://github.com/pranav-putta/nqueens) — Min-conflicts N-Queens with O(n) conflict tracking, scales to 10K+ queens.
- [AhmedNasserabdelkareem/N-Queens](https://github.com/AhmedNasserabdelkareem/N-Queens) — Hill climbing, K-beam local search, genetic algorithm, and CSP backtracking for N-Queens.
- [jp1014506/NQueensSimulatedAnnealing](https://github.com/jp1014506/NQueensSimulatedAnnealing) — N-Queens solved with simulated annealing and a cooling schedule.

## Lab 13 — Developing Fuzzy Logic Based System

- [scikit-fuzzy/scikit-fuzzy](https://github.com/scikit-fuzzy/scikit-fuzzy) — The standard SciPy fuzzy toolkit (skfuzzy): Mamdani FIS, membership functions, defuzzification, classic tipping problem.
- [Python-Fuzzylogic/fuzzylogic](https://github.com/Python-Fuzzylogic/fuzzylogic) — Fuzzy logic and fuzzy inference for Python 3 with a web GUI for experimentation and code generation.
- [aresio/simpful](https://github.com/aresio/simpful) — Lightweight fuzzy logic library with natural-language rules; Mamdani and Sugeno reasoning.
- [fuzzylite/pyfuzzylite](https://github.com/fuzzylite/pyfuzzylite) — Python port of FuzzyLite control library (6 controller types, 30+ example controllers from MATLAB/Octave).
- [caigen/scikit-fuzzy-examples](https://github.com/caigen/scikit-fuzzy-examples) — Step-by-step worked examples: membership functions, defuzzification, Mamdani/Sugeno tipping implementations.
- [jdvelasq/fuzzy-expert](https://github.com/jdvelasq/fuzzy-expert) — Python package for building Mamdani fuzzy inference systems (membership functions, T-norms, certainty factors) with tutorial notebooks.
- [Guoxuan99/Washing-Machine-Fuzzy-Logic-Controller](https://github.com/Guoxuan99/Washing-Machine-Fuzzy-Logic-Controller) — University fuzzy-logic assignment: washing machine controller with 5 inputs / 5 outputs using skfuzzy.
- [unifr-fss/fuzzy-tutorial](https://github.com/unifr-fss/fuzzy-tutorial) — University tutorial notebooks covering fuzzy control systems and fuzzy clustering with scikit-fuzzy.
