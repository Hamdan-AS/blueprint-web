## Lab 1 — Explore the usage of any documentation tool in SDLC

- [bonellia/srs-ieee-latex](https://github.com/bonellia/srs-ieee-latex) — Software Requirements Specification document template in LaTeX conforming to ISO/IEC/IEEE 29148.
- [wxinix/IEEE-29148-SRS-LaTeX-Template](https://github.com/wxinix/IEEE-29148-SRS-LaTeX-Template) — SRS LaTeX template based on the latest IEEE/ISO/IEC 29148:2018 standard, section 9.6.
- [OscarM3615/srs-template](https://github.com/OscarM3615/srs-template) — Modular SRS LaTeX template (document class + chapters) based on IEEE 830 and ISO/IEC/IEEE 29148.
- [holmeskelly/SRS-LaTeX](https://github.com/holmeskelly/SRS-LaTeX) — Modular LaTeX book template for an SRS respecting IEEE standards, with referencing macros.
- [jpeisenbarth/SRS-Tex](https://github.com/jpeisenbarth/SRS-Tex) — LaTeX template for a Software Requirements Specification that respects the IEEE standards.
- [Ashad001/Latex-Templates](https://github.com/Ashad001/Latex-Templates) — Collection of LaTeX templates for SRS, project proposals, project reports, and business proposals.

## Lab 2 — Practice any project management tool to prepare a project plan

- [opf/openproject](https://github.com/opf/openproject) — Leading open source project management suite: Gantt charts, roadmaps, agile boards, issue tracking (Jira/MS Project alternative).
- [bardsoftware/ganttproject](https://github.com/bardsoftware/ganttproject) — Free desktop PM app: task hierarchy, Gantt + PERT charts, resource load, cost; interoperates with MS Project.
- [smartqubit/projectlibre](https://github.com/smartqubit/projectlibre) — Open source replacement for Microsoft Project: Gantt, PERT, earned value costing, RBS chart.
- [makeplane/plane](https://github.com/makeplane/plane) — Modern open source project management platform (issues, cycles/sprints, roadmaps, Gantt).
