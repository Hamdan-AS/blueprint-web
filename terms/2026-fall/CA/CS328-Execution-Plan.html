Master formula reference

CPU performance
CPU Time = IC × CPI × Cycle Time
Speedup = T_old / T_new
Amdahl's Law
Speedup = 1 / ((1 − f) + f/n)
Max speedup = 1/(1−f) with n→∞
Pipeline CPI
CPI_effective = CPI_ideal + stalls_per_inst
= 1 + branch_freq×miss×penalty
AMAT
AMAT = Hit_Time + Miss_Rate × Miss_Penalty
Multi-level: L1 + L1_miss × L2_AMAT
Cache bits
Offset = log₂(block_size_bytes)
Index = log₂(sets) · Tag = 32 − idx − off
Effective access time (TLB)
EAT = H×(t+m) + (1−H)×(t+k×m+m)
H=hit rate, k=page levels, m=mem time
TLB reach
TLB_reach = TLB_entries × page_size
Page_table_size = 2^(addr−offset) × entry
RAID 5
Usable = (N−1) × disk_size
Write penalty = 4 I/Os (2 reads + 2 writes)

Top 10 tricky concepts — review before every past paper

#1
$zero forwarding trap — forwarding unit must NOT forward to $zero even if a prior instruction writes it. Hardwired to 0, cannot be overwritten.
#2
EX hazard vs MEM hazard priority — when two instructions ahead produce results for the same dest register, the more recent instruction (EX) has higher priority.
#3
Load-use hazard detection — lw followed by an ALU instruction reading the loaded value CANNOT be forwarded. The MEM result is not available until after EX needs it. 1 stall required.
#4
1-bit predictor double misprediction — correctly predicts "taken" for N-1 loop iterations, then mispredicts on exit, then mispredicts again on next loop entry. 2-bit only mispredicts once.
#5
Multi-cycle vs single-cycle paradox — multi-cycle has shorter clock (only max per-step delay) but higher CPI. Single-cycle has CPI=1 but long clock (lw path). Neither is universally faster.
#6
Every FSM instruction must return to state 0 — a missing arc permanently stalls the processor. Verify every instruction's terminal state has a "goto state 0" arc.
#7
Amdahl's Law counterintuitive result — even infinite processors give max speedup = 1/(1−f). A 10% sequential fraction caps speedup at 10× no matter what.
#8
RAID 4 bottleneck — dedicated parity disk is written on every write. RAID 5 fixes this by distributing parity strips across all disks. Write penalty (4 I/Os) is the same in both.
#9
VLIW vs Superscalar trade-off — VLIW shifts scheduling to compiler (simple hardware, static, not backward-compatible). Superscalar does it in hardware (complex, dynamic, compatible).
#10
TLB miss cost — a TLB miss for 2-level paging costs 3 memory accesses total (2 page table levels + 1 data). Page fault on top of that costs 5 ms — dominates EAT completely.
